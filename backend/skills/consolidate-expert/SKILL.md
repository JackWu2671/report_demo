# 沉淀专家知识

专家的业务经验分散在脑子里，无法被系统复用。这个 skill 的目标是把专家的经验提炼成
结构化模板，让后续所有报告都能站在专家的肩膀上。

## 工作流程

### 步骤 1：分析专家输入

调用 `analyze_expert_knowledge`，将专家描述的业务场景**完整原文**传入 `expert_text`。
不得对用户输入做任何裁剪、摘要或改写，必须把用户所说的每一个字都传进去。

工具会从知识库检索相关节点、生成大纲，并自动标注知识库尚未收录的新概念（[new] 节点）。
新节点代表专家的独特经验，是这次沉淀最有价值的部分，值得特别提示专家确认。

- `success` → 告知专家发现了哪些新节点，询问大纲结构是否需要调整
- `error` → 告知分析失败，请求专家重试

### 步骤 2：按专家意见修改（按需）

调用 `modify_outline`，传入修改指令原文。修改后用一句话确认变更，再询问是否满意。

### 步骤 3：保存为模板

调用 `save_outline_template`。

只在专家明确确认时调用（说"保存"、"就这样"、"好的"等），不要主动催促，让专家自然决定。
保存成功后告知模板名称和存储路径。

## 注意事项

大纲和新节点通过独立事件推送给前端，**绝对不要**在文字回复里输出大纲内容、节点列表或任何 Markdown 格式的结构数据。
每次工具调用后，文字回复严格控制在 1-2 句话，只说结论和下一步询问。
