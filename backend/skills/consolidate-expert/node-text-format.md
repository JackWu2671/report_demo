# 节点文本格式规格

所有工具的节点文本（`search_graph_tree` 返回的树、`md_with_ids` 大纲）均使用同一格式。

## 格式定义

```
{缩进}[L{层级} {id}] {名称}：{描述}｜条件：{条件}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `{缩进}` | 是 | 每层 2 个空格，根节点无缩进 |
| `[L{层级} {id}]` | 是 | 如 `[L3 L3_001]`、`[L4 new_002]` |
| `{名称}` | 是 | 节点名称 |
| `：{描述}` | 否 | 全角冒号开头；无描述时整段省略 |
| `｜条件：{条件}` | 否 | 全角竖线开头；无条件时整段省略 |

## 示例

```
[L2 L2_001] 企业覆盖分析：分析 OTN 站点对价值企业的覆盖现状
  [L3 L3_005] 覆盖缺口识别：识别未被 OTN 覆盖的高价值企业区域
    [L4 new_001] 高价值行业缺口：针对金融、医疗等行业量化建网机会｜条件：当存在未被覆盖的价值企业时，本节才展示
      [Q L5_012] OTN 站点未覆盖企业行政区域分布
```

## 节点 id 规则

- 知识库已有节点：id 取自 `search_graph_tree` 返回结果，如 `L3_001`、`L5_012`
- 新建节点（L2/L3/L4 可新建，query节点不可）：id 用 `new_001`、`new_002`… 顺序命名

## 条件格式规范

条件值必须写成「当……时，本节才展示」结构：

- ✅ `当存在未被 OTN 覆盖的价值企业站点时，本节才展示`
- ✅ `当低阶交叉容量利用率超过 80% 的站点数量 > 0 时，本节才展示`
- ❌ `存在未被 OTN 覆盖的价值企业站点`（缺少"当…时"结构）
